🔴 Critical Issues to Fix

1. Document Request Latency (Score: 0)

Issue: First network request is slow, causing delayed page load.

Impact: Users see blank screen for longer, high bounce rate.

2. LCP Request Discovery (Score: 0)

Issue: Largest Contentful Paint element discovered late.

Impact: Main content appears slowly, poor user experience.

3. LCP Breakdown (Score: 0)

Issue: LCP timing breakdown shows delays in multiple phases.

Impact: Slow perceived load time.

⚠️ Major Issues to Fix

4. Render Blocking Requests (Score: 0)

Issue: CSS and JavaScript files block initial page render.

Files Blocking:

  • Tailwind CDN (https://cdn.tailwindcss.com)
  • Google Fonts CSS
  • Material Symbols CSS
  • mobile-responsive.css
  • animations.css

5. Reduce Unused JavaScript (Score: 50)

Issue: Loading JavaScript that isn't used on the page.

Unused JS:

  • Tailwind CDN (~300KB, only using ~30%)
  • Google Analytics (loaded too early)
  • Flatpickr library (loaded on all pages)

6. Font Display (Score: 50)

Issue: Fonts loading without font-display: swap.

Impact: Text invisible until fonts load (FOIT).

7. Improve Image Delivery (Score: 0)

Issue: Images not optimized for delivery.

Problems:

  • No responsive images (srcset)
  • No modern formats (WebP/AVIF)
  • No lazy loading on some images
  • Large image file sizes

8. Avoid Multiple Page Redirects (Score: 0)

Issue: Redirect chains slow down initial load.

Example: http:// → https:// → www → non-www

9. Network Dependency Tree (Score: 0)

Issue: Resources loaded sequentially instead of parallel.

Impact: Waterfall effect delays page load.

10. Forced Reflow (Score: 0)

Issue: JavaScript causing layout thrashing.

Impact: Janky animations, slow interactions.

11. Minimize Main-Thread Work (Score: 50 - Mobile)

Issue: Too much JavaScript execution blocking main thread.

Impact: Slow Time to Interactive on mobile.

✅ Solutions & Implementation

Solution 1: Optimize Document Request Latency

Actions:

  1. Enable HTTP/2 or HTTP/3 on your server
  2. Use a CDN (Cloudflare, AWS CloudFront)
  3. Optimize server response time (PHP-FPM, OPcache)
  4. Implement server-side caching

PHP OPcache Configuration:

; Add to php.ini
opcache.enable=1
opcache.memory_consumption=128
opcache.interned_strings_buffer=8
opcache.max_accelerated_files=10000
opcache.revalidate_freq=2
opcache.fast_shutdown=1

Solution 2: Fix LCP Issues

Actions:

  1. Preload LCP image:
<link rel="preload" as="image" href="/images/hero-image.webp" fetchpriority="high">
  1. Optimize hero image:
<img src="hero.webp" 
     srcset="hero-400.webp 400w, hero-800.webp 800w, hero-1200.webp 1200w"
     sizes="100vw"
     alt="..."
     fetchpriority="high"
     width="1200" height="600">
  1. Inline critical CSS for above-the-fold content
  2. Defer non-critical CSS

Solution 3: Eliminate Render Blocking Resources

Replace Tailwind CDN with compiled CSS:

// Install Tailwind locally
npm install -D tailwindcss
npx tailwindcss init

// Build optimized CSS
npx tailwindcss -i ./src/input.css -o ./dist/output.css --minify

Defer non-critical CSS:

<link rel="preload" href="animations.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
<noscript><link rel="stylesheet" href="animations.css"></noscript>

Inline critical CSS:

<style>
/* Critical above-the-fold styles */
body { font-family: Inter, sans-serif; margin: 0; }
header { background: #000; }
/* ... */
</style>

Solution 4: Reduce Unused JavaScript

Defer Google Analytics:

<script>
// Load GA only after user interaction
window.addEventListener('load', function() {
    setTimeout(function() {
        var script = document.createElement('script');
        script.src = 'https://www.googletagmanager.com/gtag/js?id=G-58P4JE1SYS';
        script.async = true;
        document.head.appendChild(script);
    }, 3000); // Load after 3 seconds
});
</script>

Load Flatpickr only on pages that need it:

<?php if ($current_page === 'index' || $current_page === 'listing'): ?>
<script src="https://cdn.jsdelivr.net/npm/flatpickr" defer></script>
<?php endif; ?>

Use tree-shaking with local Tailwind build

Solution 5: Fix Font Display

Add font-display: swap to all fonts:

<link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap" rel="stylesheet">

Or use local fonts with @font-face:

@font-face {
    font-family: 'Inter';
    src: url('/fonts/inter.woff2') format('woff2');
    font-display: swap;
    font-weight: 400;
}

Solution 6: Optimize Image Delivery

Convert images to WebP/AVIF:

# Using cwebp (WebP)
cwebp -q 80 input.jpg -o output.webp

# Using avifenc (AVIF)
avifenc --min 0 --max 63 -a end-usage=q -a cq-level=23 input.jpg output.avif

Use responsive images:

<picture>
    <source srcset="image-400.avif 400w, image-800.avif 800w" type="image/avif">
    <source srcset="image-400.webp 400w, image-800.webp 800w" type="image/webp">
    <img src="image-800.jpg" 
         srcset="image-400.jpg 400w, image-800.jpg 800w"
         sizes="(max-width: 768px) 100vw, 50vw"
         alt="..."
         loading="lazy"
         width="800" height="600">
</picture>

Lazy load images:

<img src="image.webp" loading="lazy" alt="...">

Solution 7: Fix Redirect Chains

Update .htaccess to avoid multiple redirects:

# Combine HTTP to HTTPS and www to non-www in one redirect
RewriteEngine On
RewriteCond %{HTTPS} off [OR]
RewriteCond %{HTTP_HOST} ^www\. [NC]
RewriteCond %{HTTP_HOST} ^(?:www\.)?(.+)$ [NC]
RewriteRule ^ https://%1%{REQUEST_URI} [L,R=301]

Solution 8: Optimize Network Dependency Tree

Use resource hints:

<!-- Preconnect to external domains -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>

<!-- DNS prefetch for less critical domains -->
<link rel="dns-prefetch" href="https://www.googletagmanager.com">

<!-- Preload critical resources -->
<link rel="preload" href="/css/critical.css" as="style">
<link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin>

Solution 9: Prevent Forced Reflows

Batch DOM reads and writes:

// ❌ BAD - Causes layout thrashing
elements.forEach(el => {
    const height = el.offsetHeight; // Read
    el.style.height = height + 10 + 'px'; // Write
});

// ✅ GOOD - Batch reads, then writes
const heights = elements.map(el => el.offsetHeight); // All reads
elements.forEach((el, i) => {
    el.style.height = heights[i] + 10 + 'px'; // All writes
});

Use requestAnimationFrame for animations:

function animate() {
    // Update styles
    element.style.transform = `translateX(${x}px)`;
    
    if (animating) {
        requestAnimationFrame(animate);
    }
}
requestAnimationFrame(animate);

Solution 10: Minimize Main-Thread Work (Mobile)

Actions:

  1. Code splitting: Load JS only when needed
  2. Web Workers: Move heavy computations off main thread
  3. Debounce/Throttle: Limit event handler execution
  4. Lazy load: Defer non-critical JavaScript
// Debounce scroll events
function debounce(func, wait) {
    let timeout;
    return function executedFunction(...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func(...args), wait);
    };
}

window.addEventListener('scroll', debounce(function() {
    // Handle scroll
}, 100));
